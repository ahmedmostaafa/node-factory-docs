Node database

All nodes

Every buildable node, with values taken straight from the game data. Each recipe is one set. A node runs up to capacity sets per second, and its output is also multiplied by heat, bugs and prestige.

How to read a card The left chips are inputs per set and the right chips are outputs per set. Heat is what the node adds to your factory while it's working. Start slots is how many you can build before buying more in the skill tree. Open Costs & scaling for upgrade prices. Sell value added compares the Market value of the outputs with the inputs.

Categories

Source

No inputs. They create Data Stream, Energy and Server Space from nothing. Each has capacity 1 (Signal Booster: 5).

Data

Harvesters that turn Data Stream and Training Data into specialized data types.

Refining

AI Product

End products worth billions to trillions per unit. Each one needs a deep supply chain.

Logistics & Defense
